# Diagramas de arquitectura

Coloca aquí los diagramas exportados de Excalidraw o Mermaid (`.svg` recomendado, o `.png`).

1. **Excalidraw**: Menú → *Export image* → SVG (activa "Embed scene" si quieres poder reeditarlo).
2. **Mermaid**: pega el código en https://mermaid.live → *Actions* → *SVG*.
3. Guarda el archivo, ej. `public/diagrams/atlas.svg`.
4. En `src/data/projects.js`, asigna `diagram: 'diagrams/atlas.svg'` al proyecto.

La tarjeta mostrará automáticamente el botón "Ver diagrama".
